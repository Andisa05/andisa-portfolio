# Andisa Mtshali Portfolio

Personal portfolio for freelance web development: featured projects, demo sites, services, education and contact.

Plain HTML and CSS (no build step), so it deploys anywhere.

- `index.html`: the portfolio
- `demos/`: three demo sites (restaurant, law firm, salon booking dashboard)

## Deploy

**Vercel:** import this repo at vercel.com → Add New → Project → Deploy. No settings needed.

**GitHub Pages:** repo Settings → Pages → Source: "Deploy from a branch" → `main` / root.

## After deploying Sunvault Solar and Veld

`index.html` links to `https://sunvault-solar.vercel.app` and `https://veld.vercel.app`. If Vercel gives those projects different URLs, update the two links in `index.html`.
